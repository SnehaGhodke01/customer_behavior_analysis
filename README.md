# 📊 Data Analytics Project – End-to-End Workflow

## 1. Overview

This project demonstrates a complete **data analytics workflow**, from raw data to business insights and presentation.

The project covers:

* Loading and analyzing data using Python
* Performing Exploratory Data Analysis (EDA)
* Cleaning and preparing the dataset
* Running SQL queries in Microsoft SQL Server
* Building an interactive dashboard in Microsoft Power BI
* Creating a structured analytical report
* Designing a presentation using Gamma

The goal is to showcase practical, job-ready skills in data analysis, SQL, and business intelligence.

## 2. Dataset

* Format: CSV file
* Type: Structured business dataset (e.g., sales/customer/operations data)
* Contains:

  * IDs (Customer/Product/Order)
  * Dates
  * Categories
  * Numeric metrics (Sales, Revenue, Quantity, etc.)

The dataset was cleaned and validated before analysis.

## 3. Tools & Technologies

* **Python** – Data loading, EDA, and cleaning
* **Pandas, NumPy** – Data manipulation
* **Matplotlib / Seaborn** – Visual analysis
* **Microsoft SQL Server** – SQL queries and data analysis
* **Microsoft Power BI** – Dashboard development
* **Gamma** – Presentation creation

## 4. Project Steps

### 1. Data Loading

* Imported dataset into Python
* Checked structure and data types

### 2. Exploratory Data Analysis (EDA)

* Summary statistics
* Trend analysis
* Distribution checks
* Correlation review

### 3. Data Cleaning

* Removed duplicates
* Handled missing values
* Standardized formats
* Created calculated fields

### 4. SQL Analysis

* Uploaded cleaned data to SQL Server
* Wrote queries using:

  * SELECT, WHERE
  * GROUP BY
  * JOIN
  * Aggregate functions (SUM, AVG, COUNT)
* Calculated KPIs and business metrics

### 5. Dashboard Creation

* Connected Power BI to SQL Server
* Built KPI cards and charts
* Added filters and slicers
* Designed clean, business-focused layout

### 6. Reporting & Presentation

* Created a written report with key insights
* Designed a professional presentation using Gamma
* Highlighted findings and recommendations
